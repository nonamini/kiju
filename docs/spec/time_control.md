# 棋樹 (joseki-tree) - 対局時計・持ち時間ルール仕様書 (Game Clock & Time Control Rules Spec)

本書は、AIスパーリング対局および模擬対局において、実戦さながらの臨場感とタイムマネジメント訓練を実現するための「対局時計（クロック）・各種持ち時間ルール（切れ負け・秒読み・フィッシャー・早指し）」および「AI側の持ち時間追従・スケール思考時間制御」の正式仕様を定義する。

---

## 1. 機能概要と目的

### 1.1 目的
- **実戦タイムプレッシャーの再現**: 将棋ウォーズ（切れ負け）、Abemaトーナメント（フィッシャー）、プロ公式戦・アマ大会（秒読み・早指し）など、多様な競技環境を忠実にシミュレートする。
- **AI側の思考スケール連動**: 人間側だけにタイマーを設けるのではなく、AI側にも持ち時間・残り時間に応じた思考時間（秒読みなら1秒未満〜設定秒数、切れ負けなら残り時間配分）を動的に割り当て、実戦的な時間切迫戦（時間攻め・寄せ合い）を可能にする。

---

## 2. サポートする持ち時間ルール一覧

| ルール名 | 識別子 | 基本時間 | 追加 / 秒読み | 特徴・競技シーン |
| :--- | :--- | :--- | :--- | :--- |
| **切れ負け** | `SUDDEN_DEATH` | 3分 / 5分 / 10分 | なし (0秒) | 将棋ウォーズ・席道場早指し。時間切れ＝即敗北。 |
| **持ち時間 ＋ 秒読み** | `BYOYOMI` | 5分〜30分 (0分可) | 30秒 / 60秒 | アマ大会・奨励会・プロ公式戦標準。基本消費後は一手ごとのカウントダウン。 |
| **フィッシャー・モード** | `FISCHER` | 3分 / 5分 | 1手ごとに +5秒 / +10秒 | Abemaトーナメント、Chess.com標準。早く指せば残り時間が増加。 |
| **超早指し (1手N秒)** | `HYPER_BULLET` | 0分 | 1手 10秒 / 20秒 | 瞬発力・反射神経訓練。 |

## 3. 対局時計（Game Clock）データモデル

`src/types/clock.ts` に配置する型定義：

```typescript
export type TimeControlRule = 
  | 'SUDDEN_DEATH'  // 〇分切れ負け
  | 'BYOYOMI'       // 持ち時間 ＋ 秒読み
  | 'FISCHER'       // フィッシャー (+N秒)
  | 'HYPER_BULLET'; // 1手〇秒

export interface TimeControlConfig {
  rule: TimeControlRule;
  initialTimeSec: number;   // 初期持ち時間 (秒、例: 3分=180, 10分=600)
  byoyomiSec?: number;      // 秒読み秒数 (例: 30, 60)
  incrementSec?: number;    // フィッシャー加算秒数 (例: 5, 10)
}

export interface PlayerClockState {
  remainingTimeSec: number; // 残り持ち時間 (ミリ秒精度でカウント)
  currentByoyomiSec: number;// 秒読みの現在秒数
  isByoyomi: boolean;       // 秒読み突入フラグ
  isTimeUp: boolean;        // 時間切れフラグ
}

export interface MatchClockState {
  config: TimeControlConfig;
  black: PlayerClockState;
  white: PlayerClockState;
  activeColor: 'b' | 'w';
  isPaused: boolean;
}
```

## 4. AIエンジンの思考時間スケーリング（動的 USI `go` 制御）

Wasm将棋エンジン（USIプロトコル）に対し、設定された持ち時間ルールおよび残り時間に応じて、動的に最適な探索パラメータ（`btime` / `wtime` / `byoyomi` / `movetime`）を生成して渡す。

### 4.1 USI `go` コマンドマッピング
```
1. 切れ負け / フィッシャーの場合:
   go btime <残り先手ms> wtime <残り後手ms> binc <先手加算ms> winc <後手加算ms>

2. 持ち時間＋秒読み（本時間残あり）:
   go btime <残り先手ms> wtime <残り後手ms> byoyomi <秒読みms>

3. 秒読み突入後（本時間0）:
   go byoyomi <秒読みms>

4. 超早指し (1手N秒):
   go movetime <指定ms>
```

### 4.2 AI思考時間の安全スケール制御（クライアントWasm防衛）
- **ブラウザ・Wasm安全マージン**:
  - 例えば「30秒の秒読み」の場合、通信遅延やメインスレッド描画遅延による時間切れ反則負けを防ぐため、AIエンジンには **「設定秒数 × 80%〜90%」**（例: 30秒なら25秒）を上限として割り当てる。
- **切れ負けでの時間配分**:
  - 残り時間 / 想定残り手数（通常20〜40手）で1手あたりの持ち時間を算出し、終盤になるほど時間切迫した高速着手を行う。

## 5. UI表現（1画面完結スタジオへの統合）

### 5.1 駒台（KomadaiView）の横に対局時計を統合
盤面を圧迫せず、対局者情報（先手・後手）のすぐ脇に、デジタル対局時計を配置。

```
【先手側 駒台ヘッダー】
 ▲ ユーザー   [ 04:25 ] (秒読み: --)   [ 持ち駒: 飛, 歩x2 ]

【後手側 駒台ヘッダー】
 △ AI (端攻め名人)  [ 00:00 ] (秒読み: 18秒 ⏳)   [ 持ち駒: 金, 銀 ]
```

### 5.2 視覚・音声フィードバック
- **秒読みカウントダウン**: 秒読み10秒以下になると、数字が赤くパルス発光し、警告音（または「10秒... 9... 8...」の読み上げ音声）を発動可能。
- **フィッシャー加算エフェクト**: 指した瞬間にタイマーの横に `+5s` がフワッと浮かび上がる視覚エフェクト。
- **時間切れ判定**: タイマーが0になった瞬間に即座に `TIME_UP`（時間切れ負け/勝ち）モーダルを表示。

### 5.3 プリセット選択
右パネルの【AI対局】設定に、おなじみの時間設定プリセットを用意：
- ⚡ **3分切れ負け** (将棋ウォーズ弾丸)
- ⏱️ **10分切れ負け** (ウォーズ標準)
- 🏆 **10分 ＋ 秒読み30秒** (公式戦・大会風)
- 🌊 **5分 ＋ フィッシャー5秒** (Abemaトーナメント風)
- ⚙️ **カスタム** (自由に秒数・加算を設定)
